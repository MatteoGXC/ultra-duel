On a Mac, open **Apple menu > About This Mac**. Choose Apple Silicon if it shows an Apple M-series chip; choose Intel if it shows an Intel processor.

Open the Mac DMG and drag Ultra Duel into Applications. Keep the files in Application Support to preserve local data. Intel version 0.1.12 supports account deck backups after signing in. Mac updates are installed manually from a new DMG.

The installer downloads the content files automatically. Download the installer for your platform; the Content BIN files, update data, and automatic Source code archives are not standalone game installers.
